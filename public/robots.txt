# Open Bible Stories — crawl policy
#
# Everything on this site is public and licensed CC BY-SA 4.0, and the point
# of the site is to be found in the language of the query. Every crawler is
# allowed: search engines, live-retrieval agents (the fetchers behind ChatGPT
# search, Perplexity, Claude search, Copilot, Gemini grounding) AND bulk
# training crawlers. Each is named in its own group so a broader per-agent
# rule elsewhere cannot override it.
#
# TRAINING POLICY (intentional, decided 2026-09-11 in #15): allow all,
# including training. OBS is CC BY-SA 4.0; a model that learned the stories
# in a language spreads them further, which is what the licence is for.
# Cloudflare's managed robots.txt for this zone must therefore NOT prepend
# `ai-train=no` or `Disallow: /` for GPTBot, Google-Extended, ClaudeBot,
# CCBot and the rest — that setting lives in the Cloudflare dashboard, not
# in this file, and the served file must match this one. See README →
# "Crawlers and AI policy".
